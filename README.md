# Syntecxhub_Sales_Performance_Dashboard
## Objective
To analyze raw sales data and build an interactive Power BI dashboard
that shows sales trends, top and low-performing products, regional and
category performance, and key business KPIs to support decision-making.

## Dataset
- Name: Superstore Sales Dataset
- Source: Kaggle
- Records: 5,901 rows orders from 2019 to 2020
- Key fields: Order Date, Region, Category, Sub-Category, Product Name,
Sales, Profit

## Tools Used
- Microsoft Power BI Desktop
- Power Query (data cleaning)
- DAX (measures and KPIs)

## Project Steps
1. Imported the raw dataset into Power BI
2. Cleaned the data: removed null values and duplicates, fixed data types
3. Created a date table and DAX measures
4. Analyzed monthly, quarterly, and yearly sales trends
5. Identified top-selling and low-performing products
6. Compared sales by region and category
7. Built an interactive dashboard with slicers

## KPIs
- Total Revenue: 1.57M.
- Total Profit: 175.26K.

## Key Insights
- West. generated the highest revenue
- Office Supolies. was the most profitable category
- 3D Systems Cube Printer,2nd Generation,Magneta. was the top seller; AVery 479. performed lowest
- Sales peaked in Month(December 244,,542.89) and Quarter(Qtr 4 586,542.35)
